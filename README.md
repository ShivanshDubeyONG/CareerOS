# AI CareerOS 🚀

An AI-powered platform that helps students improve their resumes, identify skill gaps, prepare for interviews, and build personalized learning roadmaps.

## Tech Stack

- FastAPI
- React
- PostgreSQL (Supabase)
- Google Gemini
- Docker
- TailwindCSS

## Features

- Resume Upload ✅
- Resume Parsing 
- ATS Score
- Job Description Matching
- Skill Gap Detection
- AI Learning Roadmap
- GitHub Analyzer
- Interview Generator

## Project Status

Currently under active development.
